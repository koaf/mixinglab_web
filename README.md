# Meloa Web

既存のMeloaのパネル配置・配色を引き継いだ、静的サイトとして動くマルチトラックMIXアプリです。Web Audio APIで音声を端末内で処理し、PWAとしてインストール・オフライン利用できます。

公開先: https://koaf.github.io/mixinglab_web/

## Web版の起動・開発

Node.js 22以降を使用します。

```powershell
npm ci
npm test
npm run build
npm run dev
```

`http://127.0.0.1:4173` を開きます。`dist/` が配信対象で、サーバー処理・外部CDN・APIキーは不要です。`file://` からの起動には対応していません。

ブラウザーでの動作確認:

```powershell
npx playwright install chromium
npm run test:browser
```

## Web版の機能と保存

- WAV / MP3 / FLAC / OGGの読み込み（ブラウザーのデコーダー対応に依存）、同梱デモ、最大12トラック・1本10分・合計20分。
- マルチトラック・ソース波形・ミキサー、クリップ移動、音量・パン・ミュート・ソロ、40操作の取り消し／やり直し。
- EQ、コンプレッサー、リバーブ、ディレイ。「適用」で再生・書き出しに反映。
- 48 kHz / 24 bitのステレオWAV書き出し。出力ピークは±0.98に制限。
- `.meloa.json` は元音源をBase64で含むWeb版形式。別端末に持ち運べます。デスクトップ版への再読み込みには非対応です。
- デスクトップ版のセッションを開く場合、参照先の元音源を「読み込み…」から追加します。VST3・ピッチ／タイミング補正は再現しません。元のファイルを保管してください。
- 編集内容と音源はIndexedDBへ自動保存します。ブラウザーのサイトデータ消去・保存容量不足で失われる場合があるため、大切な作業はファイルに保存してください。最大セッションファイル256 MB、元音源1ファイル120 MBです。長い音源は大きなメモリーを使います。
- VST3、ピッチ／タイミング補正、録音はWeb版未対応です。Rust版の音声エンジンとは異なるためエフェクトの音は完全には一致しません。

Space / Home / End / 9 / 0 / `=` / `-` / `\` と Ctrl（MacはCommand）+ I / O / S / Z / Shift+Z を利用できます。プロパティでセッション名・トラック名・開始位置を変更できます。

## PWA・GitHub Pages

HTTPSまたはlocalhostでService Workerが有効になります。初回のアプリ・デモ音源のキャッシュが完了するとオフラインで起動できます。対応ブラウザーのインストール操作、iOSではSafariの共有メニューの「ホーム画面に追加」を利用してください。更新が通知されたら、すべてのMeloaタブを閉じて開き直してください。アプリを更新するときは `web/sw.js` のキャッシュバージョンも更新します。

GitHubの **Settings → Pages → Source → GitHub Actions** を選択します。`.github/workflows/pages.yml` がmainへのpush時にテスト・ビルドし、`dist/` だけをGitHub Pagesへ配信します。相対URLで動くためプロジェクト配下のURLにも対応します。

公開用の `koaf/mixinglab_web` は独立した履歴とし、`web/`、Web用スクリプト・テスト、デモ音源、必要なアイコン・設定だけを含めます。既存の非公開リポジトリの履歴や販売用資料は含めません。
