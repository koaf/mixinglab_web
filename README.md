# Meloa WebEditor

既存のMeloaのパネル配置・配色を引き継いだ、静的サイトとして動くマルチトラックMIXアプリです。Web Audio APIで音声を端末内で処理し、PWAとしてインストール・オフライン利用できます。

公開先: https://koaf.github.io/mixinglab_web/

PCではそのままミキサーを開き、スマートフォンではインストールを案内するトップページを表示します。インストール済みのアプリからは直接ミキサーを起動します。スマホでも「まずはブラウザーで使ってみる」から使用できます。トップページをPCで確認する場合は `/?welcome=1`、ミキサーへの直接リンクは `/mixer.html` です（公開サイトではリポジトリのパスの後に付けます）。

## Web版の起動・開発

Node.js 22以降を使用します。

```powershell
npm ci
npm test
npm run build
npm run dev
```

`http://127.0.0.1:4173` を開きます。`dist/` が配信対象で、サーバー処理・外部CDN・APIキーは不要です。`file://` からの起動には対応していません。

ブラウザーでの動作確認:

```powershell
npx playwright install chromium
npm run test:browser
```

## Web版の機能と保存

- WAV / MP3 / FLAC / OGGの読み込み（ブラウザーのデコーダー対応に依存）、同梱デモ、最大12トラック・1本10分・合計20分。
- マルチトラック・ソース波形・ミキサー、クリップ移動、音量・パン・ミュート・ソロ、40操作の取り消し／やり直し。
- EQ、コンプレッサー、リバーブ、ディレイ、ピッチシフター。「適用」で再生・書き出しに反映。
- ピッチシフターは±12半音（0.1半音刻み）。デスクトップ版の `mix-core::pitch_shift` をそのままWebAssembly化し、Web Worker内で処理します。長さとテンポを保ち、「フォルマントを保持 (声質を変えない)」はデスクトップ版と同じく初期状態でオンです。ノート単位の補正には「ピッチ / タイミング」タブを使います。長い音源では処理に時間がかかります。元音源は保持し、波形表示は処理前の音源を表示します。
- 48 kHz / 24 bitのステレオWAV書き出し。出力ピークは±0.98に制限。
- `.meloa.json` は元音源をBase64で含むWeb版形式。別端末に持ち運べます。デスクトップ版への再読み込みには非対応です。
- デスクトップ版のセッションを開く場合、参照先の元音源を「読み込み…」から追加します。VST3は再現しません。ピッチ／タイミング補正の設定は引き継ぎます。元のファイルを保管してください。
- 編集内容と音源はIndexedDBへ自動保存します。ブラウザーのサイトデータ消去・保存容量不足で失われる場合があるため、大切な作業はファイルに保存してください。最大セッションファイル256 MB、元音源1ファイル120 MBです。長い音源は大きなメモリーを使います。
- VST3、録音はWeb版未対応です。トラック全体のキー変更はピッチシフターを使います。Rust版の音声エンジンとは異なるためエフェクトの音は完全には一致しません。

Space / Home / End / 8 / 9 / 0 / `=` / `-` / `\` と Ctrl（MacはCommand）+ I / O / S / Z / Shift+Z を利用できます。プロパティでセッション名・トラック名・開始位置を変更できます。

## ピッチ / タイミング編集

「ピッチ / タイミング」タブ、またはキー `8` で選択トラックを解析します。デスクトップ版と同じYIN解析、TD-PSOLA補正、DTWガイド合わせをWebAssemblyで実行します。ボーカルなど単音素材向けで、和音・ノイズの多い素材では検出が不安定になる場合があります。

- ノートを上下にドラッグすると半音単位で音程を変更します。Altを押しながらは微調整。ダブルクリックで元の音程の最寄りの半音、↑↓で選択ノートを半音ずつ移動。
- 左右へのドラッグで発音位置、左右の端で開始／終了を調整します。隣のノートや空白が伸縮して吸収します。数値欄からも音程・開始・終了を指定できます。クリップ全体の長さは維持します。
- 空いた場所のドラッグで範囲選択、Ctrl/Command+Aで全選択、Shift/Ctrl/Command+クリックで複数選択。
- キー・スケール、補正量、ドリフトを指定し「スケールに合わせる」でまとめて補正できます。選択がなければ全ノートが対象です。
- 別のトラックをガイドに選び、「ガイドに合わせる」で±0.4秒以内の発音位置のずれを自動調整。強さは0〜100%。「タイミングを戻す」でリセットします。
- 再生・WAV書き出し・自動保存・セッション保存・取り消し／やり直しに反映します。元の音源は保持します。ピッチ／タイミング補正は内蔵エフェクトの前に処理します。

## PWA・GitHub Pages

HTTPSまたはlocalhostでService Workerが有効になります。初回のアプリ・デモ音源のキャッシュが完了するとオフラインで起動できます。対応ブラウザーのインストール操作、iOSではSafariの共有メニューの「ホーム画面に追加」を利用してください。更新が通知されたら、すべてのMeloa WebEditorタブを閉じて開き直してください。アプリを更新するときは `web/sw.js` のキャッシュバージョンも更新します。

GitHubの **Settings → Pages → Source → GitHub Actions** を選択します。`.github/workflows/pages.yml` がmainへのpush時にテスト・ビルドし、`dist/` だけをGitHub Pagesへ配信します。相対URLで動くためプロジェクト配下のURLにも対応します。

公開用の `koaf/mixinglab_web` は独立した履歴とし、`web/`、Web用スクリプト・テスト、デモ音源、必要なアイコン・設定だけを含めます。既存の非公開リポジトリの履歴や販売用資料は含めません。
